1安裝

整個安裝過程只需一次下載，無須建立 .env 檔案，亦無須安裝任何開發工具。

  1. 前往下載頁開啟 jarvis-automation.com/download，按「Download for Mac」。下載檔案約 18 MB。
  2. 安裝開啟下載好的 JARVIS_latest_aarch64.dmg，將 JARVIS 圖示拖入 Applications 資料夾。
  3. 首次開啟在「應用程式」中按兩下 JARVIS。此版本已通過 Apple 公證，不會出現「無法打開」的攔截訊息。
  4. 授權麥克風（可選）首次使用語音功能時，macOS 會要求麥克風權限。不使用語音則可略過。
系統需求 Apple Silicon Mac（M1 或更新），macOS 12 或以上。若要使用免費本機模型，需要 macOS 14 或以上，此限制來自 Ollama 而非 JARVIS。

安裝後佔用多少空間

項目大小何時下載
JARVIS 應用程式約 30 MB安裝時
本機資料庫少於 5 MB首次啟動
離線語音辨識模型148 MB僅在啟用離線語音辨識時

換言之，日常使用 JARVIS 只佔用數十 MB。所有大型下載都必須由你主動啟用，不會在背景自動發生。第 6 節說明如何查看及清理。

2首次設定

首次開啟時會出現三步設定導引。可隨時按「稍後繼續設定」離開，之後從頂欄或電郵頁重新開啟。

步驟一：設定電郵 AI

選擇由哪個 AI 處理郵件，然後按測試。JARVIS 只有在測試通過後才會套用設定，避免在未能運作的情況下切換。可選項目包括 OpenAI、Amazon Bedrock，以及本機模型（見第 4 節）。

步驟二：連接電郵工作區

按下連接後會開啟瀏覽器進行 Google 授權。JARVIS 只要求 gmail.readonly 唯讀權限，不能代你寄信。

會看到「未經驗證的應用程式」警告 JARVIS 的 Google OAuth 驗證仍在審核中，因此測試期間會出現此警告，需要按「進階」再繼續。這亦是 Beta 名額有限的原因：Google 在完成驗證前，限制測試用戶總數為 100 名。

步驟三：取得第一份實用結果

從已下載的郵件中揀選數封，建立一個群組並填寫指示（例如「整理客戶查詢並列出待辦」）。JARVIS 會產生分析，每項結論都附有來源郵件引用，可逐項核對。

沒有 Gmail 也可以 略過步驟二仍可使用聊天、語音、日程及自動化功能。電郵工作區則需要連接後才能使用。

3選擇 AI 供應商

JARVIS 需要一個 AI 來源。你可以提供雲端供應商的 API 密鑰，或完全使用免費本機模型。

使用 API 密鑰

前往「設定 → API 密鑰」貼上密鑰，即時生效。密鑰儲存在 macOS 鑰匙圈，不會寫入資料庫，亦不會離開這部 Mac。

供應商說明
Gemini預設供應商，一般用途使用 Flash 級別以控制成本
OpenAI可作後備，亦可用於郵件分析
Claude可作後備
Amazon Bedrock在設定中輸入 AWS 憑證，適合較複雜的任務

只需提供其中一個。若提供多於一個，JARVIS 會按「設定 → 模型 → 供應商優先次序」自動切換後備。

API 費用由你直接支付 JARVIS 目前不提供代管 AI 服務，費用直接來自你的供應商帳戶。「設定 → 成本」可查看實際用量。若不想付費，請使用下一節的本機模型。

4設定免費本機模型

本機模型完全免費，無須 API 密鑰，郵件及對話內容不會離開這部 Mac。代價是需要一次過下載數 GB 模型，速度亦視乎硬件。

  1. 安裝 Ollama前往 ollama.com/download/mac 下載並拖入「應用程式」。JARVIS 可以代你啟動 Ollama，但不能代你安裝。
  2. 開啟本機 AI 設定在 JARVIS 中前往「設定 → 模型 → 本機模型端點」。JARVIS 會自動檢查 macOS 版本、記憶體及可用磁碟空間。
  3. 選擇模型JARVIS 會按記憶體推薦合適的 Qwen 模型。按下下載後會顯示進度，可隨時取消。
  4. 加入優先次序下載完成並通過測試後，將本機端點加入供應商優先次序即可使用。

推薦模型

Mac 記憶體推薦模型下載大小建議預留磁碟
8 GBqwen3.5:2b約 2.7 GB8 GB
16 GBqwen3.5:4b約 3.4 GB10 GB
24 GB 或以上qwen3.5:9b約 6.6 GB15 GB

Qwen 系列對繁體中文及廣東話的處理明顯優於同等大小的其他模型。同一畫面亦可連接 vLLM 或任何 OpenAI 相容的端點。

本機模型不會自動轉交雲端 郵件分析使用本機模型時，若本機模型失敗，JARVIS 不會把郵件內容改送雲端，而是顯示錯誤。助手聊天的後備機制是另一套設定，會在設定中清楚標示。
模型檔案由 Ollama 保管 模型儲存在 ~/.ollama，不在 JARVIS 的資料夾內，因此不會出現在 JARVIS 的儲存空間統計中。移除模型請使用 Ollama，或執行 ollama rm qwen3.5:4b。

5日常操作

快捷鍵

操作快捷鍵
開啟聊天Cmd + K
關閉聊天Esc
按住說話Cmd + Shift + J
顯示或隱藏桌面背景模式Cmd + Shift + W

亦可說出「Hey Jarvis」喚醒，或按選單列圖示選擇 Show JARVIS。

電郵工作區

將相關郵件歸入群組並填寫指示，JARVIS 會產生附來源引用的分析。群組指示可隨時修改後重新分析。歸入群組的郵件會完整保留，不會被自動清理處理。

草擬回覆

JARVIS 只會建立 Gmail 草稿，永遠不會代你寄出。所有草稿都要你在 Gmail 中檢視後才發送。

自動化

「自動化」頁可建立定時工作，例如每日早上整理收件匣或產生每日簡報。每次執行的結果都有紀錄可供檢視。

桌面背景模式

「設定 → 外觀 → 桌面背景」可將 JARVIS 顯示為動態桌面背景，介面會在其他視窗後方。按 Cmd + Shift + W 重新取得操作焦點。

6儲存空間管理

JARVIS 會持續向前同步較舊的郵件，因此本機資料庫會隨時間增大。0.4.0 起提供完整的查看及清理工具。

查看用量

前往「設定 → 儲存空間」。畫面會顯示總用量，並分為資料庫、語音及 AI 模型、網頁快取、舊備份四項，同時列出已儲存的郵件數目及對話記錄數目。

自動清理

預設保留 90 日，於每次啟動時執行。可在同一畫面改為 30 日、180 日、1 年，或完全關閉。清理規則如下：

  • 超過期限的郵件只會移除內文，主旨、寄件人及預覽會保留，郵件列表及引用仍然可用。
  • 已歸入郵件群組的郵件永不清理，因為歸入群組代表你明確要求保留。
  • 超過期限的對話記錄、快取郵件、用量統計及每日簡報會被刪除。

手動釋放空間

項目影響
清除網頁快取安全，會自動重建
刪除舊備份安全，舊版本遺留的副本
刪除已下載的模型安全，需要時會重新下載
移除已儲存的郵件內文保留主旨及預覽，已分組郵件完整保留
刪除所有對話記錄無法復原
資料庫位置 ~/Library/Application Support/jarvis/ — 儲存空間畫面底部會顯示實際路徑。

7私隱與資料

保存在本機的資料

對話、工作、郵件副本及同步內容全部存放在這部 Mac 的 SQLite 資料庫。JARVIS 沒有伺服器，亦沒有雲端同步。

憑證

所有 API 密鑰、Google 更新權杖、GitHub 及 Notion 憑證均存放在 macOS 鑰匙圈，不會以純文字寫入資料庫。

會傳送到外部的內容

使用雲端供應商時，推論並非在本機進行 預設供應商是 Gemini。你傳送的訊息及需要分析的郵件內容，會送往該供應商的 API。若要所有內容都留在本機，請按第 4 節設定本機模型，並將本機端點排在供應商優先次序首位。

JARVIS 不會做的事

  • 不會代你寄出郵件，只會建立草稿。
  • 不會讓 AI 讀取本機檔案或剪貼簿。
  • 建立日曆項目時不會加入與會者，避免內容被自動送往其他人的日曆。

8疑難排解

出現「未經驗證的應用程式」警告

屬預期情況。Google OAuth 驗證審核期間會顯示此警告，按「進階」再繼續即可。

本機 AI 顯示需要 macOS 14

此限制來自 Ollama。JARVIS 本身支援 macOS 12 及 13，在這些版本請改用 API 密鑰。

Ollama 未能及時啟動

手動開啟 Ollama 應用程式，等待選單列圖示出現後返回 JARVIS 重試。

模型下載顯示核對碼不符

JARVIS 會核對下載檔案的 SHA-256，不符即棄用。通常是網絡中斷或代理伺服器所致，重試即可。

磁碟空間不斷增加

前往「設定 → 儲存空間」查看分項。若自動清理已關閉，重新開啟並按「立即清理」。

JARVIS 無法啟動，提示資料庫錯誤

將 ~/Library/Application Support/jarvis/jarvis.db 移至其他位置後重新開啟，JARVIS 會以全新資料庫啟動。憑證存放在鑰匙圈，不會因此遺失。

找不到視窗

按選單列的 JARVIS 圖示選擇 Show JARVIS。若處於桌面背景模式，按 Cmd + Shift + W。

回報問題或申請 Beta 名額

前往 jarvis-automation.com 頁面底部的申請表格，或使用網站的聯絡頁。Beta 名額上限 100 名，額滿為止。

回報問題時請附上 JARVIS 版本（設定頁底部）、macOS 版本，以及重現步驟。
