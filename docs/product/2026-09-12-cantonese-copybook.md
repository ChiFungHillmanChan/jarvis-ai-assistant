# JARVIS 香港繁體書面語逐頁文案手冊

更新日期：2026-09-12。此文件以使用者最新要求為準，取代同日早期版本的粵語口語規範。沿用檔名以保留既有連結；目前所有新增或修訂的產品中文、工作說明及 AI 中文回覆均採用繁體書面語。

本手冊對照 v0.3.0 已有流程及本輪工作目錄的文字更新。GitHub、Notion、Obsidian 的新授權入口屬本輪整合工作，必須以實際建置、連接及原生驗收結果確認完成狀態。本文件不是新版本已發布、外部服務已授權或公司合規已完成的證明。

## 1. 一致的文字與資料規範

### 中文風格

- 使用清晰、自然的繁體書面語，例如「已儲存設定」「請選擇要加入的群組」「未能讀取憑證，請重試」。不採用粵語口語字詞或強制中英夾雜。
- 可使用「你」作為稱呼；面向公司文件以具體動作為主，避免逐句加入「你」或過度敬語。
- 保留 GitHub、Notion、Obsidian、Gmail、OpenAI、Ollama 等品牌名稱，以及必要模型 ID、API 欄位及檔案路徑。中文說明優先使用「API 密鑰」「存取權杖」「連接端點」。
- 同一功能使用一致名稱：AI 助理、電郵工作區、連接服務、設定導引、群組記憶、自動排程。
- 狀態統一為「載入中」「同步中」「執行中」「已完成」「已儲存」「尚未設定」「未能讀取」。不要把未知狀態顯示成零、未連接或成功。
- 介面、文件、程式新增文案、commit／PR 說明及回覆均不使用 emoji。

### 語言設定彼此獨立

| 設定 | 目前用途 | 相容性要求 |
|---|---|---|
| `ui_locale=zh-HK` | 香港繁體中文介面與地區格式 | 保留既有值與使用者選擇；不改成新的 locale 以迫使資料遷移 |
| `language=yue` | 既有中文回覆設定，現在要求繁體書面語 | 保留儲存值；顯示名稱與 system prompt 需反映書面語 |
| `language=bilingual` | 純英文要求以英文回覆；中文與混合要求使用書面中文，保留必要英文術語 | 中文部分不模仿口語 |
| `language=en` | 英文回覆 | 保留英文功能，不因更新覆蓋設定 |
| `stt_language=yue` | 粵語語音辨識 | 忠實轉錄原話，不為配合書面介面而改寫輸入 |
| 朗讀聲線 | 播放已生成文字 | 粵語聲線可朗讀書面中文，不代表文字必須改成口語 |

電郵分析的預設提示使用繁體書面語。助理與每日摘要的中文輸出亦遵循相同風格。介面切換不會更改 AI 供應商、語音辨識語言、朗讀聲線、Gmail 授權或使用者自訂指示。

### 原文與來源

原始郵件、筆記、合約、使用者自訂標題、人名、公司名、型號、金額、單位及引用保留原文。需要翻譯時另標「參考翻譯」，不覆寫來源。`[郵件 #123]` 不翻譯或重新編號。語音逐字稿及測試中的口語來源亦保留原文。

AI 自行撰寫的摘要使用書面語，例如：「客戶要求於星期五前確認交貨日期，運費尚待確認。」未有證據的期限、幣種或承諾標為「待確認」「原信未明確說明」，不得自行補上。有效引用提供核對入口，不保證推論正確。

### 日期、時區與金額

顯示例子：「2026 年 9 月 12 日 14:30（香港時間）」。目前多數畫面使用 macOS 本機時區；介面為香港中文不代表所有時間自動改為香港時間。提示應使用實際 formatter 的時區，例如「時間以 {timezoneLabel} 顯示」。獨立工作時區選項尚待實作。

跨境時間按事件日期計算夏令時間，不固定假設香港與倫敦相差七小時。日期型資料保留日期語意；instant 保留 offset／UTC。金額使用 `HK$1,280`、`US$120`；來源只有 `$120` 時顯示「$120（幣種待確認）」，不自行換算。

## 4. 設定導引

### 第一步：設定電郵 AI

| 場景 | 標準文案 |
|---|---|
| 標題 | 設定電郵 AI |
| 既有設定 | 系統會沿用已儲存的憑證及已連接的信箱。AI 助理、日曆及語音可按需要另行設定。 |
| 處理方式 | 本機 AI — 無須 API 密鑰／OpenAI — 自備帳戶，限合資格地區／AWS Bedrock — 自備公司帳戶 |
| 尚未測試 | 已儲存設定不代表連接可用，請先進行測試。 |
| 通過測試 | 本次開啟 App 後的測試已通過。服務狀態可能改變，實際使用時仍可能出現錯誤。 |
| API 密鑰 placeholder | 留空會沿用已儲存密鑰 |
| 官方入口 | 開啟官方 API 密鑰頁面 |
| 測試按鈕 | 測試並儲存／測試並使用此模型 |
| 測試同意 | 測試會傳送合成文字，可能產生少量費用。之後分析郵件時，所選郵件內容、指示及有效記憶會傳送至此供應商。 |
| 測試成功 | 合成測試通過，所選模型已儲存供電郵工作區使用。 |
| 儲存後畫面失敗 | 電郵設定已儲存，但畫面未能更新。請重新開啟導引以核對。 |

地區支援與費用說明必須依供應商最新官方資料核對；不要將已有 API 密鑰或外地伺服器描述為香港商用資格。公司 AWS 憑證由適當管理員提供，顯示實際地區及模型。

### 第二步：連接電郵工作區

標題：「連接電郵工作區」。權限說明：「JARVIS 會要求唯讀郵件權限，並將可讀副本儲存於此 Mac。本次連接不會要求寄信或日曆權限。斷開連接會保留副本；刪除本機帳戶才會清除副本。」

按鈕：「連接 Gmail 並同步首批郵件」「同步所選信箱」。數量提示：「每次最多同步 50 封，並非完整備份。」部分成功：「本次同步僅完成部分，請重試。」後續資料：「仍有較舊的郵件，可在工作區繼續載入。」

授權未完成時顯示「請在瀏覽器完成 Google 授權，再返回 JARVIS」。OAuth callback 收到 code 不代表 token exchange、帳戶驗證與儲存已完成，不能提早顯示「已連接」。

### 第三步：取得第一份實用結果

說明：「選取同一客戶或項目的 2–5 封簡短郵件；加入群組不會變更 Gmail 標籤。」欄位：「群組名稱」「此群組的整理指示」。

預設指示：「以繁體書面語整理已確認的日期、待回覆問題及下一步。保留原信引用，並標示尚未確認的資料。」只在使用者未輸入指示時採用，不覆蓋自訂內容。

按鈕：「建立群組並分析」「開啟原信以核對結果」「開啟電郵工作區」。若 AI 尚未通過測試：「分析前，請返回第 1 步測試所選 AI。」若尚無郵件：「尚無本機郵件。可返回上一步同步，或先開啟工作區，稍後再連接。」

費用與品質提示：「沒有雲端 token 費用；磁碟用量、電費及效能取決於 Mac 規格。小型模型可能無法提供有效的郵件引用。引用或容量檢查失敗時，分析會停止，可另選模型；系統不會自動轉用雲端。」

顯示模型完整 tag、核實或標為估算的下載大小、實際 RAM 及磁碟空間。未知磁碟空間顯示「未能取得可用磁碟空間」。沒有總下載量時不要虛構百分比；取消下載只影響當前工作，不取消另一個頁面或使用者的作業。

Assistant 的進階模型鏈使用「加入助理模型鏈」，不能表示已套用至電郵。首次安裝的系統權限、下載等待及供應商條款不能以「一鍵」隱藏。

## 6. 電郵工作區

### 信箱與郵件

| 場景 | 標準文案 |
|---|---|
| 簡介 | 集中管理多個信箱的本機副本，透過群組整理郵件與記憶。 |
| 主要操作 | 連接 Gmail 帳戶／同步最近郵件／載入更舊郵件／由最新郵件重新掃描 |
| 連接成功 | 已連接。請按「同步最近郵件」下載首批郵件。 |
| 授權界線 | 每個 Gmail 帳戶需分別授權；此處的連接與日曆設定互相獨立。 |
| 同步數量 | 已儲存 {saved} 封郵件。 |
| 分頁限制 | 每次最多同步 50 封，不代表已備份整個信箱。 |
| 搜尋 | 搜尋本機郵件；主旨、寄件人或內容 |
| 選取 | 全選本頁／已選 {count} 封 |
| 空白結果 | 沒有符合條件的本機郵件。請調整搜尋或篩選條件，或選擇一個信箱進行同步。 |
| 空主旨 | （無主旨） |
| 閱讀提示 | 選取一封郵件，即可在此查看本機內容。 |
| 無可讀文字 | 此郵件沒有可顯示的文字。 |
| 副本說明 | 郵件可讀文字儲存於此 Mac；部分格式可能只能取得摘要，附件尚未下載。 |
| 斷開 | 斷開連接，保留郵件 |
| 刪除 | 刪除帳戶及本機郵件 |

帳戶刪除確認：「將刪除帳戶、本機郵件、相關群組連結，以及以此帳戶郵件為來源的記憶；其他自行新增的記憶會保留。Gmail 中的原始郵件不受影響。」

### 群組、記憶與分析

欄位：「群組名稱」「個人指示」「群組記憶」「內容」「種類」「狀態」「來源郵件編號」「到期日」。種類：「事實／偏好／承諾」。狀態：「進行中／已完成」。按鈕：「加入群組」「移出此群組」「分析此群組」「查看來源」。

指示 placeholder：「例如：以繁體書面語整理，列出需要我回覆的問題及截止日期。」記憶說明：「記錄已確認的事實、偏好及承諾。分析不會自動新增記憶。」

分析範圍：「分析範圍涵蓋整個群組，不受左側信箱篩選影響。最多納入最近 50 封郵件，本機模型另有容量限制。」來源必須屬於相同群組；已完成或已到期的記憶不會納入分析。

雲端同意：「我明白執行分析時，群組郵件內容、個人指示及有效記憶會傳送至 {provider}。」本機說明：「僅使用本機 Ollama；失敗時不會自動改用雲端。」

結果顯示實際 provider、model、未納入郵件數量及來源按鈕。引用檢查失敗：「模型回覆的郵件引用無效或缺漏，請更換模型或重試。」不要將引用有效寫成事實已驗證。

群組刪除確認：「將刪除群組、指示及記憶；本機郵件仍然保留。」記憶刪除確認：「此記憶刪除後無法還原。」

## 8. 工作總覽、自動排程與日曆

### 自動排程

標題：「工作總覽」「排程與執行紀錄」。說明：「已啟用的排程會在背景執行」「系統只會執行已啟用的排程。開啟此頁面不會啟動新工作。」

欄位：「名稱」「排程」「下次執行」「上次執行」「狀態」「指示」「執行紀錄」。狀態：「已啟用／已暫停／執行中／已完成／失敗」。操作：「管理自動排程／暫停／恢復／啟用／重新整理」。

空白提示：「目前沒有已啟用的排程」「此自動排程尚無執行紀錄」「本次執行沒有文字結果」。排程預覽使用真實計算結果；暫停期間需標示「暫停期間的預覽」，不能寫成確定會執行。

### 日曆

標題：「你的日程」。時間說明使用實際時區。操作：「新增活動」「同步日曆」「選擇日期」「今日」。空白提示：「此日期沒有已同步的活動。」

活動欄位：「標題」「開始」「結束」「備註」「活動詳情」「時間」「地點」「參加者」「全日」。狀態：「已確認／待確認／已取消」。錯誤：「結束時間必須晚於開始時間。」

新增說明：「此活動會加入你的日曆；如有需要，可稍後在 Google Calendar 加入受邀者。」成功：「已在 Google Calendar 建立個人活動，沒有發出邀請。」

## 9. GitHub、Notion、Obsidian 連接入口

本節是本輪整合的文字契約。只在對應原生指令已接通時顯示操作；狀態必須來自當前憑證／權限檢查。開啟外部程式不等於授權，儲存權杖不等於存取驗證成功。

| 服務 | 主要操作 | 權限說明 |
|---|---|---|
| GitHub | 開啟 GitHub／連接 GitHub／重新檢查／中斷連接 | 首次連接會開啟 GitHub 授權頁，需使用者確認；顯示實際請求權限 |
| Notion | 開啟 Notion／連接 Notion／重新檢查／中斷連接 | 在 Notion 官方流程選擇可存取範圍；JARVIS 只使用已提供的讀取功能 |
| Obsidian | 開啟 Obsidian／選取資料庫並授權／重新檢查／移除授權 | 透過本機資料夾選擇器授權指定資料庫，不要求雲端登入；讀取範圍僅限所選資料庫 |

GitHub device flow 顯示「授權碼」「開啟授權頁」「等待授權完成」「取消」。未提供公開 Client ID 時，顯示實際待設定狀態及所需步驟，不能宣稱所有使用者已可一鍵連接。Client ID 是公開應用程式識別碼，不是 API 密鑰或 personal access token。

Notion 授權失敗顯示清楚的重試方法；若伺服器沒有提供所需功能，不應以舊快取或已存 token 回報成功。OAuth 授權、既有 integration token 及可見頁面範圍應清楚區分。

Obsidian 授權說明：「選擇要供 JARVIS 讀取的 Obsidian 資料庫。JARVIS 只讀取所選範圍，不會修改筆記。」資料夾必須是有效資料庫，不能默認取得整個使用者目錄。移除授權不刪除筆記；資料庫移動或權限失效時要求重新選取。

狀態詞：「未連接」「等待授權」「已連接」「已授權」「已儲存，尚未驗證」「需要處理」「暫時未能讀取狀態」。顯示帳戶或資料庫名稱時保留原文；診斷與報告不披露完整地址、token 或私人筆記。

GitHub 工具頁使用「審查與議題收件匣」「同步 GitHub」「項目詳情」「儲存庫」「作者」「更新時間」「在 GitHub 開啟」。Notion 工具頁使用「Notion 來源」「同步 Notion」「頁面」「來源詳情」「最近編輯」「在 Notion 開啟」。

Notion 頁面的同步範圍以實際資料欄位為準。若只保存標題及來源資料，明示「已同步頁面標題與來源資料，尚未同步正文」，即使其他工具可按需讀取正文亦不能稱為整個工作區已備份。

## 10. 設定、API 密鑰與語音

### 模型、密鑰及 Google

設定說明：「管理 JARVIS 在此 Mac 上的運作方式。」模型鏈說明：「JARVIS 會依次嘗試已啟用的供應商。電郵分析有獨立模型設定。」

密鑰說明：「密鑰儲存於 macOS 鑰匙圈。儲存密鑰不代表已驗證供應商連接或可用額度。」欄位留空保留現有密鑰；輸入新密鑰才取代；移除按鈕應明示刪除已儲存的密鑰，不顯示密鑰原文。

Assistant Google 與 Mail Gmail 分開顯示用途。切換或中斷 Assistant Google 時，確認文案需如實說明撤銷授權及清除助理郵件快取、日曆活動和摘要的範圍，同時明示獨立 Mail 工作區副本是否保留。

AWS 憑證、地區及模型必須與實際設定一致。「已儲存」不能改成「已測通」。不要要求已安裝 App 的一般使用者編輯 `.env`。

### 語言、朗讀與喚醒

介面欄位：「介面語言」。說明：「僅變更 JARVIS 選單及操作介面。助理回覆與語音辨識語言需另行設定。」儲存失敗：「未能儲存介面語言。關閉 JARVIS 前請重試。」

回覆語言：「英文／繁體書面語／雙語」。語音辨識：「自動辨識／英文／廣東話」，保留實際支援選項與儲存值。聲線使用「廣東話聲線」，不要把聲線選擇當成文字風格。

語音錯誤文案：「尚未取得麥克風權限」「未能辨識本次內容，請重說一次或輸入文字」「本機辨識模型未能載入」。這些是既有錯誤的標準呈現方式，不表示已新增「測試麥克風」或「試聽」按鈕。

喚醒詞標示「實驗功能」。如設定了 Gemini API 密鑰，完整語音指示目前會先使用雲端辨識，再以本機 Whisper 作後備；不要將其寫成完全離線。粵語辨識、實際音訊播放、聲線可用性需分別驗收。

## 11. 下載、更新與可恢復錯誤

更新操作使用「更新至 v{version}」「更新中 {percent}%」「重試更新」。目前按更新按鈕會下載、安裝並重新啟動；若未提供獨立檢查頁，不新增虛構的「檢查更新」入口。

| 實際情況 | 書面語文案 | 下一步 |
|---|---|---|
| 缺少密鑰 | 尚未設定 {provider} API 密鑰。 | 開啟對應設定 |
| 憑證不可讀 | 未能讀取已儲存的憑證。請檢查鑰匙圈存取權限後重試。 | 檢查權限；不因讀取錯誤要求重新申請 |
| 網絡失敗 | 未能連接 {provider}，請檢查網絡後重試。 | 重試 |
| 權限或模型不可用 | 此帳戶暫時無法使用 {model}。 | 核對權限或另選模型；需有實際錯誤證據 |
| 額度不足 | 帳戶暫時沒有可用額度，或已達用量上限。 | 檢查官方帳單頁；不自動充值 |
| 合成測試失敗 | 模型未通過示範資料核對，請嘗試其他模型。 | 更換模型或重試 |
| 引用缺漏 | 模型回覆的郵件引用無效或缺漏，請更換模型或重試。 | 核對模型能力 |
| 本機容量不足 | 此群組資料超出本機模型可處理的範圍。 | 減少群組內容或自行選用其他模式 |
| 模型尚未安裝 | 所選模型尚未安裝，尚未傳送郵件內容。 | 下載模型或另選已安裝模型 |
| 下載失敗 | 模型下載未完成。 | 重試；不顯示為完成 |
| 設定衝突 | 設定已在另一個畫面變更。請重新載入後重試。 | 重新載入，保留新設定 |
| Gmail 部分同步 | 成功下載的郵件已儲存，仍有部分未完成。 | 重試相同同步操作 |
| 授權逾時 | 本次授權等候時間已過。 | 重新開始授權，不重用失效 callback |
| 狀態不可用 | 暫時未能讀取狀態。 | 重新整理；不當作已斷開 |
| 工作區錯誤 | 未能載入此工作區。 | 重試 |

錯誤文案只能對應已證實的原因，不能分析任意 raw provider body 猜測帳戶狀態。不得將 API 密鑰、OAuth code、callback URL、完整回覆 body、私人郵件或筆記放進畫面與診斷。也不能在未確認交易狀態時保證「所有資料仍然保留」。

## 12. 無障礙、插值與資料邊界

- 為圖示按鈕提供本地化名稱，例如「關閉搜尋」「開始另一項工作」「開啟完整對話分頁」「停止朗讀」。placeholder 不能代替 label。
- 進度使用 `role=status`，錯誤使用 `role=alert`。百分比更新應適度播報；未知進度顯示文字狀態。
- 取消、重試與確認刪除不可被長文案遮擋。對話框開啟時管理焦點，關閉後返回合理位置。
- 中文輸入法正在組字時，Enter 不應誤送出指示。文字改寫不改變快捷鍵語意。
- `{count}`、`{saved}`、`{omitted}` 使用後端真實數量，區分零與未知；不將本機總數冒充本次新增數。
- `{model}` 使用完整模型 ID，`{provider}` 使用固定可信名稱，`{timezoneLabel}` 使用真實格式化時區。
- `{title}`、`{subject}`、`{groupName}`、帳戶及資料庫名稱保留原文並正確 escape；不得當成 HTML 或新的指令。
- 中英 catalog 的 key 與插值名稱保持一致。儲存的自訂分頁標題不因 locale 切換被翻譯覆蓋。

## 13. 驗收與尚未實作項目

文字驗收先檢查實際主流程，再處理長錯誤、tooltip、aria-label、下載通知及原生 callback；不能只翻譯標題。既有 i18n 測試檢查 key／插值一致性、自訂標題保留與設定相容性。文字改寫配合 TypeScript、既有前端與 Rust 測試，不為每句翻譯新增鏡像測試。

原生驗收應覆蓋已登入及未連接狀態、語言切換與重開、下載取消、錯誤恢復、權限撤銷、群組指示保留及來源開啟。使用合成來源測試，不改寫使用者真實郵件或筆記。新外部授權需真正完成對應服務流程，不能以假 token 或瀏覽器 mock 代替。

以下仍需獨立產品與工程工作：免 API 密鑰的代管 AI、完整團隊帳戶／權限、跨裝置同步、永久分析歷史、工作時區選擇、群組模板、自動分類、結構化跟進看板、語音聽寫覆核、診斷匯出及完整公司試用驗證。不得僅以文案顯示為已完成。

對外介紹必須符合當前版本：不得宣稱「全部設定零確認」「所有郵件永不離機」「所有語音完全離線」「已完成團隊管理」或「已通過香港法規」，除非已有對應實作與驗證證據。新授權入口的實際可用性與 v0.3.0 歷史發行紀錄分開記錄。
