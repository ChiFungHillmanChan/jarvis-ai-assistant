- 新增及修訂的介面、研究報告、文案手冊和實作方案採用繁體書面語。GPT、Claude、Gemini、本機 AI 與 Bedrock 共用中文書面語提示規則，每次讀取已儲存的回覆語言偏好。
- 保留英文選項、既有 `zh-HK`／`yue` 設定值、語音辨識設定及來源原文；不改寫使用者的郵件、記憶或逐字轉錄。

## 原生 App 驗收

使用 `native-mail-qa.py` 啟動隔離的 `JARVIS Native QA.app`，資料庫包含兩個已斷開的合成信箱、合共 120 封合成郵件。測試資料庫與正式 JARVIS 分開，啟動環境不繼承 API key，排程暫停。

- 「連接服務」頁顯示三個服務入口及繁體書面語；左上角按鈕保留紅色關閉、黃色最小化、綠色放大次序。
- GitHub 未設定公開 Client ID 時，連接按鈕停用並顯示登記及儲存入口，不誤報已連接。
- Obsidian 原生選擇器可選取合成資料庫，回傳已驗證連接及資料庫名稱。再次開啟選擇器後取消，原有連接保留，並顯示取消訊息。
- 「開啟 Obsidian」可喚起已安裝的 Obsidian；未聲稱已開啟指定資料庫，因官方 URI 按資料庫名稱定位，同名或未登記資料庫可能產生歧義。
- 隔離模式的 Notion 授權按鈕回傳明確測試限制，不會啟動真實帳戶授權。
- 最終程式重新建置後，Obsidian 連接仍可保留。從設定頁中斷後，「連接服務」頁隨即顯示尚未連接；再次重新建置及啟動後，撤銷狀態仍然保留。
- 最後修正設定頁三處口語文案後，重新執行前端 21 項測試及原生封裝，確認介面顯示「本機 AI 設定及端點」。
- 驗收後隔離資料庫完整性為 `ok`，仍有兩個帳戶及 120 封合成郵件，兩篇合成 Obsidian 筆記原檔保留。測試 App 已退出。

## 尚待完成的帳戶設定與驗收

- **GitHub：**尚未提供 JARVIS 專用公開 Client ID，須登記 OAuth App 並啟用 Device Flow。程式流程及合成回應已測試，但真實帳戶授權、組織批准及 SSO 尚未驗收。
- **Notion：**首次實際使用需要使用者在官方頁面登入及確認工作區權限。本輪沒有完成真實 Notion 授權；工作區方案、管理員政策及實際搜尋權限仍需帳戶驗收。
- **Obsidian：**原生驗收使用合成筆記；未透過 JARVIS 讀取使用者真實筆記，也未用雲端模型處理筆記。
- 提示詞及路由測試不能保證模型每次輸出均符合書面語；真實中文回覆品質仍需持續驗收。

正式 `/Applications/JARVIS.app`、GPT 選擇、OpenAI API key、Gmail 授權及正式郵件資料均未因本輪隔離測試而變更。此分支未包含新的公證、GitHub Release 或公開 updater 發行。
